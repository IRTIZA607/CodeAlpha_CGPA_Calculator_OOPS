# 📘 CGPA Calculator using OOPS in C++

## 📌 CodeAlpha Internship – Task 1

This project is a **CGPA Calculator** implemented in **C++ using Object-Oriented Programming (OOPS)**.
It calculates the CGPA of a student based on grades and credit hours entered by the user.

---

## 🚀 Features
- Object-Oriented Programming approach
- Uses `vector` to store multiple courses
- Input validation for grades and credit hours
- Calculates total credits, total grade points, and CGPA
- Simple and beginner-friendly code

---

## 🧱 OOPS Concepts Used
- Classes and Objects  
- Encapsulation  
- Constructors  
- Abstraction  
- STL (`vector`)  

---

## 📊 Grade Mapping
| Grade | Grade Points |
|------|--------------|
| A | 10 |
| B | 8 |
| C | 6 |
| D | 4 |
| F | 0 |

---

## 🧠 Logic
1. Input number of courses
2. For each course:
   - Input grade and credit hours
   - Validate inputs
3. Calculate:
   - Total Credits
   - Total Grade Points
4. Compute CGPA using:
```
CGPA = Total Grade Points / Total Credits
```
